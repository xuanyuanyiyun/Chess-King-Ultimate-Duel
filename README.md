# 象棋王：绝招对决 (Xiangqi King: Ultimate Showdown)

《象棋王：绝招对决》是一款融合了传统中国象棋规则与现代二次元科幻“技能大招”机制的创新网页游戏。它完全由纯前端技术打造，**单文件、免安装、完全离线**，非常适合随时随地在任何设备上游玩。

## 🎮 核心玩法与特色

### 1. 双模式选择
- **人机对决 (单机)**：与内置的“天网 AI”进行对战。AI 拥有简单的价值评估逻辑，并且在能量积满时会自动释放毁灭性的技能。
- **双人联机 (同屏)**：支持两名玩家在同一台设备（如平板、电脑屏幕）上轮流操作对弈。

### 2. 能量与绝招系统 (Ultimate Skills)
传统象棋结合了现代 RPG 的能量条机制：
- **积攒能量 (SP)**：玩家每走一步棋增加 10 点 SP，吃掉对方棋子额外增加 10 点 SP。上限为 100 点。
- **红方绝招【天地同寿】**：当红方能量满 100 时可手动触发。牺牲己方场上随机一个非将帅棋子，直接摧毁对方场上随机一个非将帅棋子。
- **黑方绝招【暗影突袭】**：黑方的专属技能。人机模式下由 AI 自动触发；双人模式下黑方玩家手动触发。

### 3. 科技感美术与标准棋谱
- **赛博朋克 UI**：深色背景、发光网格、霓虹色的红黑棋子与动态呼吸的技能按钮。
- **精准的棋盘绘制**：包含标准的楚河汉界，以及精确绘制的“炮角”和“兵角”十字/半十字标记。
- **动态特效**：技能释放时伴随带有屏幕缩放与渐隐动画的巨大全息文字（Canvas 渲染）。

### 4. 视角翻转功能 (Flip Board)
专为双人同屏对战设计！点击界面下方的 **【🔄 视角翻转】** 按钮，棋盘将进行 180 度翻转，棋子上的汉字以及楚河汉界也会自动倒转，确保坐在屏幕对面的玩家能获得最佳视角。

## 🛠️ 技术特点与合规性

- **极度轻量化 (Ultra-Lightweight)**：所有 HTML、CSS 和 JavaScript 逻辑均压缩在单一的 `index.html` 文件中，文件大小不到 20KB。
- **完全离线 (100% Offline)**：**无任何外部依赖**。不引用外部图片、不加载第三方字体库、不需要 React/Vue/Three.js 等任何外部框架。
- **数据持久化**：使用浏览器的 `localStorage` 在本地安全地记录您的胜负场次。
- **高性能渲染**：游戏画面采用原生 HTML5 Canvas 绘制，保证 60fps 流畅运行；UI 层采用现代 CSS3 响应式布局。
- **全端适配**：响应式设计完美适配手机、平板和桌面浏览器。

## 🚀 运行与使用方法

1. **获取游戏**：下载本目录下的 `象棋王绝招对决.html` 文件。
2. **启动游戏**：直接双击该 HTML 文件，使用任何现代浏览器（Chrome、Edge、Safari、Firefox 等）打开即可。
3. **开始游玩**：
   - 在主菜单选择模式（人机或双人）。
   - 轮到你的回合时，点击己方棋子，棋盘会用绿色圆点高亮显示可走路径。
   - 点击绿色圆点即可完成走子。
   - 当下方能量条（SP）达到 100 时，技能按钮会高亮闪烁，点击即可释放绝招逆转战局！

## 📜 规则说明

1. 基础走子、吃子规则完全遵循经典中国象棋规则（马走日、象走田、炮翻山等）。
2. 红方（聂无悔）固定先行。
3. 胜利条件：将死对方的“将”或“帅”。
4. 任何一方释放绝招后，会直接跳过本回合，由对方继续行棋。
